This folder contains the Week 3 practical laboratory, focused on understanding the impact of SIMD instructions on program performance and throughput.

## Exercises

### Exercise A

Implementation of floating-point vector multiplication using AVX2 intrinsics.

### Exercise B

Implementation of a reduction operation over a floating-point vector using AVX2 intrinsics.

### Exercise C

Implementation of matrix multiplication using the vectorized operations developed in Exercises A and B.
